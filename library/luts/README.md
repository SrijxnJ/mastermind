# Grade LUTs (free presets from the Brain's recipes)

Four 33-point `.cube` LUTs, generated by `tools/luts.py` from recipes in the Brain. They replace paid preset packs.
They expect normal phone footage (Rec.709 SDR). Shoot or export HDR/HLG/Dolby Vision as SDR first, or the look will be off.

| File | Recipe (source) | Use for | Before/after |
|---|---|---|---|
| `moody.cube` | Highlights −35, blacks +12 (lifted), saturation −15 % [L10]. Add the soft vignette separately (−40 in-app, or ffmpeg `vignette=angle=PI/5`) | Talking-head, desk, night, reflective tech | `moody_before_after.png` |
| `gym-contrast.cube` | Deep blacks, punchy S-curve, slight teal shadows / orange highlights, a touch cooler [SP gym grade, L07] | Gym pillar | `gym-contrast_before_after.png` |
| `travel-warm.cube` | Warm golden mids, shadows lifted a little, highlights pulled and slightly desaturated [L06, SP golden hour, KH] | Travel pillar, golden hour | `travel-warm_before_after.png` |
| `tech-clean.cube` | Neutral mids, cool highlights, clean black point, gentle contrast, saturation ×0.97 (our take) | Tech/PC pillar, screens, RGB | `tech-clean_before_after.png` |

The "after" half of each PNG is rendered by ffmpeg's `lut3d` from the `.cube` file itself, so the picture also shows the file loads.
Sources: moody on `post/01_cover.jpg`, gym on a frame of the incline set (1.5 s, caption band cropped off), travel on `post/09_cliff.jpg`, tech on `post/06_selfie.jpg`.

## Use a LUT at 60–80 %, then fix exposure

A LUT is a fixed transform: it can't correct a shot that's too dark or too bright. Set exposure and white balance first, apply the LUT,
then lower its strength if it's too much. Check skin last (the orange-HSL skin check from the grade spec).

App menu names move between versions; these paths were written from the apps' documented LUT import features, not tested on Srijan's phone.

## CapCut (phone and desktop)

1. Get the `.cube` onto the phone (AirDrop, Files, Drive, WhatsApp "document").
2. Desktop CapCut: **Adjust → LUT → Import** and pick the `.cube`. Drag the **Intensity** slider (start around 70).
3. Mobile CapCut: select the clip → **Adjust** → **LUT** (or **Filters → Import LUT** on some versions) → import from Files.
   If your build has no LUT import, use desktop CapCut, or bake the LUT in with ffmpeg (below) and import the graded clip.
4. Apply to the clip, or add an **Adjustment layer** across the timeline and put the LUT on that, so every clip gets it.

## VN (VlogNow)

1. Select the clip → **Filter** → the **+ / Import** (LUT) tab → **Import from Files** → pick the `.cube`.
2. It appears in your filter list. Apply it and set the strength (start around 70).
3. Use **Apply to all** for a matching look across the reel.

## Instagram Edits

Edits has its own filter set. Look for a LUT/filter import in your version; if there isn't one (not verified here), there are two ways round it:
- Grade in CapCut or VN first, export, then edit in Edits; or
- Bake the LUT in with ffmpeg (below) and import the graded file into Edits.

## DaVinci Resolve / Premiere (if you edit on the laptop)

- Resolve: copy the `.cube` files into the LUT folder (Project Settings → Color Management → Open LUT Folder), **Update Lists**, then right-click a node → LUT.
- Premiere: Lumetri Color → Creative → Look → Browse… → pick the `.cube`; set Intensity.

## ffmpeg (bake the look into a file)

```bash
# whole clip, full strength
ffmpeg -i in.mp4 -vf "lut3d=library/luts/moody.cube" -c:a copy out.mp4

# L10 moody with its soft vignette
ffmpeg -i in.mp4 -vf "lut3d=library/luts/moody.cube,vignette=angle=PI/5" -c:a copy out.mp4

# 70 % strength: blend the graded and original versions
ffmpeg -i in.mp4 -filter_complex "[0:v]split[a][b];[b]lut3d=library/luts/gym-contrast.cube[g];[a][g]blend=all_mode=normal:all_opacity=0.7" -c:a copy out.mp4

# still photo (carousel slide)
ffmpeg -i photo.jpg -vf "lut3d=library/luts/travel-warm.cube" -q:v 2 photo_graded.jpg
```

## Rebuild or add a look

Edit the recipe functions in `tools/luts.py` (one small function per look) and run:

```bash
.venv/bin/python -I tools/luts.py --compare moody=/path/to/frame.jpg
```

It rewrites `library/luts/*.cube` and, for each `NAME=IMAGE`, the `NAME_before_after.png`. It needs only numpy and ffmpeg.
